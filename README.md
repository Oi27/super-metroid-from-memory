# super metroid from memory
super metroid recreated from memory

This project uses the SMART editor: https://edit-sm.art/download.html

SMART guides:
- https://begrimed.com/tmp/smmm2tmp/chapter0.html
- https://wiki.metroidconstruction.com/doku.php?id=sm:editor_utility_guides:smart

## Guidelines

1. Do not expose yourself to vanilla Super Metroid (playing, watching streams, map rando, etc.) while contributing to this project, insofar as it is possible.
2. Do not provide *any* feedback regarding the accuracy any rooms or assets being edited during the development of this hack. Limit your feedback to stuff like bug reports.
3. Please claim one room at a time.
4. Within each area, it is advised to pick a room connecting from a pre-existing finished room.
5. Do not assign ID numbers to doors, items, etc. SMART has a feature that can do that automatically instead.
6. If a room has a particularly difficult technical challenge (e.g. bosses, PLMs, events, door/room ASM), just ignore it and make the room anyway. Somebody else can fix it for you later.
7. Be excellent to each other.

## How to Claim a Room

- Go to the Issues tab.
- Go to the issue corresponding with the area the room is in.
- Claim your room, and state the ID number (in hex) you're using (it's best if we go sequentially).
- At your convenience, add your claimed room to rooms.txt (for credits).
